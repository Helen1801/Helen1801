# Тест-кейсы для мобильного приложения

**Задание:** 
Написание тест-кейсов для проверки функциональности мобильного приложения.

**Что было сделано:**
* Изучены требования к функционалу приложения.
* Описаны предусловия и шаги для воспроизведения.
* Написаны позитивные тест-кейсы (проверка успешного добавления задач).
* Написаны негативные тест-кейсы (проверка пустых полей и валидации).
* Проверены граничные значения (например, ограничение по количеству символов).
